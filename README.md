MLBB Location Changer v0.1.0
Первый исходный проект Android-приложения для тестовой подмены GPS-координат. Не использует Google Play Services, Firebase, аналитику или VPN. Root не требуется.

Что уже есть
Kotlin + Jetpack Compose.
Выбор из 20 российских городов и поиск по названию/региону.
Запуск foreground-сервиса, который публикует тестовые GPS и network координаты.
Остановка подмены.
Ссылка на настройки разработчика для выбора приложения фиктивного местоположения.
Ограничения первой версии
Это не меняет IP-адрес, SIM-регион, Wi-Fi геолокацию, регион аккаунта или сервер Mobile Legends.
Некоторые приложения обнаруживают Mock Location или используют собственные источники геолокации.
На прошивках Huawei поведение нужно проверить на реальном P60; энергосбережение EMUI может останавливать фоновые процессы.
Карта, произвольная точка, избранное и автоматическое определение текущего статуса будут добавлены после проверки базовой подмены.
Сборка APK на Windows
Установить Android Studio и Android SDK Platform 35.
Распаковать архив.
Открыть папку MLBB_Location_Changer в Android Studio.
Дождаться Gradle Sync.
Выбрать Build → Build Bundle(s) / APK(s) → Build APK(s).
APK будет в app/build/outputs/apk/debug/app-debug.apk.
Нужен JDK 17 (Android Studio обычно поставляет встроенный JBR). Сборка использует Android Gradle Plugin 8.7.3 и Kotlin 2.0.21.

Настройка на телефоне
Установить APK.
Включить параметры разработчика (если ещё не включены).
Открыть параметры разработчика → приложение для фиктивных местоположений.
Выбрать MLBB Location Changer.
Открыть приложение, разрешить геолокацию, выбрать город и нажать «Включить».
Для завершения нажать «Остановить» в приложении или в постоянном уведомлении.
Приватность
Приложение не отправляет выбранные координаты на сервер и не содержит аналитических SDK. Координаты передаются только локальному Android LocationManager как тестовое местоположение.

Исправление v0.1.1: приложение не отображается в списке Mock Location
В AndroidManifest.xml добавлено обязательное объявление:

<uses-permission android:name="android.permission.ACCESS_MOCK_LOCATION" />

После пересборки и переустановки:

Включи «Для разработчиков» в настройках телефона.
Открой «Выбрать приложение для фиктивных местоположений» (название пункта может отличаться в EMUI).
Выбери MLBB Location Changer.
Вернись в приложение и нажми «Включить».
Android не показывает системный запрос на выбор Mock Location автоматически: выбор приложения выполняется вручную в настройках разработчика.
